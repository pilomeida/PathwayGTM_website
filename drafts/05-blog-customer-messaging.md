# [Working title] The GTM Failure Five Sources Keep Naming

## Angle
This is an "external validation" piece, not a Pathway-originated argument — the strength is precisely that five unrelated sources (vendor content, practitioner opinion, a data-platform company) independently converge on the same failure cluster without citing each other. That convergence is more credible than any single source's claim, and it's a good format to demonstrate Pathway synthesizes real external research rather than only asserting its own framework.

## Outline

**Hook:** If five people who've never met independently diagnose your business with the same problem, that's not a coincidence you can dismiss as one vendor's angle.

**H2 — Five Sources, One Diagnosis**
Briefly name each source and its one-line finding (Cognism's six-step framework naming messaging as a core failure point; HubSpot's persona/buying-center mechanics; House of Revenue's six failure areas naming messaging/positioning explicitly; ZoomInfo's data-lens argument still circling back to ICP; the LinkedIn practitioner piece's leadership-behavior angle). Keep this section scannable — short paragraph or list per source, not deep dives (those exist elsewhere in the wiki if a reader wants more).

**H2 — Why Messaging Fails Aren't Branding Problems**
The reframe this WP needs to land: messaging inconsistency isn't a copywriting issue, it's a pipeline issue — deals stall or convert poorly because sales, marketing, and delivery aren't describing the same offer to the same customer for the same reason.

**H2 — The Common Thread: Nobody Owns It**
Cross-reference House of Revenue's CRO-ownership argument — messaging failures often trace back to no single accountable owner, which is also a live open question inside N²'s own Governance & Steering WP. Worth an explicit forward-link once that WP has its own article.

**H2 — What Consistent Messaging Actually Requires**
Practical translation: message hierarchy, single source of truth for positioning, and — tying back to Article 4 — messaging that's derived from the job-to-be-done, not from what's easiest to say in a deck.

**Blockquote candidate:** "When five sources who've never spoken to each other reach the same diagnosis, the problem isn't the messaging — it's how confident everyone was that they didn't have one."
